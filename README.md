# Dynamic Island для Windows

Музыкальный «Dynamic Island» в стиле Apple для Windows 11, написанный на Rust + [Slint](https://slint.dev).

- 🎵 Работает с **Spotify**, **Яндекс Музыкой** (приложение и сайт), браузерами, AIMP, VLC и любым плеером, который показывает обложку в системном меню громкости Windows
- ⏯ Пауза, переключение треков, перемотка перетаскиванием полосы
- 🎤 **Синхронизированные тексты песен** из Spotify, Яндекс Музыки и [LRCLIB](https://lrclib.net), клик по строке перематывает к ней
- 🫧 Плавная «пружинная» анимация, акцентный цвет берётся из обложки, эквалайзер
- 🪶 Около 30 МБ памяти (≈5 МБ приватной), 0% CPU, когда ничего не играет
- 🎮 Прячется в полноэкранных играх и видео
- 🔒 Без серверов: всё работает локально на вашем компьютере

## Установка

1. Скачайте `dynamic-island.exe` из раздела [Releases](../../releases).
2. Запустите. Появится значок в трее (чёрная «таблетка»).
3. Включите музыку, и остров появится вверху экрана.

Наведите курсор на остров, чтобы раскрыть его. Клик по свёрнутому острову закрепляет его открытым, клик по фону открытого — сворачивает.

Меню в трее: настройки, автозапуск с Windows, очистка кэша текстов, выход.

## Тексты песен

По умолчанию тексты берутся из **LRCLIB**: бесплатно, без регистрации. Для русскоязычной музыки и более полного покрытия подключите свои аккаунты. Данные хранятся только у вас в `%APPDATA%\DynamicIsland\config.toml` и отправляются только в Spotify / Яндекс.

Порядок источников по умолчанию — `auto`: сначала сервис того плеера, который сейчас играет, затем остальные.

### Spotify (`spotify_sp_dc`)

1. Откройте https://open.spotify.com и войдите в аккаунт.
2. F12 → **Application** (Chrome/Edge) или **Хранилище** (Firefox) → **Cookies** → `https://open.spotify.com`.
3. Скопируйте значение cookie **`sp_dc`** в `spotify_sp_dc` в конфиге.
4. В трее нажмите **«Применить настройки»**.

Cookie действует около года. Если тексты Spotify перестали загружаться, обновите его.

### Яндекс Музыка (`yandex_token`)

Нужен OAuth-токен Яндекс Музыки. Самый простой способ:

1. Откройте в браузере
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
2. Войдите и разрешите доступ. Браузер перейдёт на адрес вида `…#access_token=y0_XXXX&…`.
3. Скопируйте значение `access_token` в `yandex_token` в конфиге и нажмите **«Применить настройки»**.

> ⚠️ Spotify и Яндекс Музыка **не предоставляют официального API для текстов**. Используются внутренние API их веб-/мобильных клиентов, поэтому они могут перестать работать после обновлений сервисов. В этом случае автоматически используются остальные источники. Никому не передавайте свои `sp_dc` и токен: это доступ к вашему аккаунту.

## Настройки

`%APPDATA%\DynamicIsland\config.toml` (меню трея → «Открыть настройки»):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `ui.hide_when_idle` | `true` | Прятать остров, когда ничего не играет |
| `ui.expand_on_hover` | `true` | Раскрывать при наведении (иначе — по клику) |
| `ui.compact_lyrics` | `true` | Текущая строка текста в свёрнутом острове |
| `ui.visualizer` | `true` | Анимированный эквалайзер (≈2–3% одного ядра во время воспроизведения) |
| `ui.top_offset` | `8` | Отступ от верха экрана, px |
| `ui.hide_in_fullscreen` | `true` | Прятать в полноэкранных приложениях |
| `lyrics.providers` | `["auto"]` | Порядок: `"spotify"`, `"yandex"`, `"lrclib"` |
| `lyrics.offset_ms` | `150` | Сдвиг синхронизации текста |

## Сборка из исходников

Нужны [Rust](https://rustup.rs) и Visual Studio Build Tools (C++).

```bash
cargo build --release
```

Готовый файл: `target\release\dynamic-island.exe`.

> Если проект лежит в очень глубокой папке и компоновщик пишет `LNK1104`, задайте короткий путь для сборки: `set CARGO_TARGET_DIR=C:\di-target`.

## Как это устроено

| Модуль | Что делает |
|---|---|
| `src/media.rs` | Windows GSMTC: трек, обложка, позиция, управление. Работает на событиях, без опроса |
| `src/lyrics/` | LRCLIB, Spotify (web-player token + TOTP → `color-lyrics`), Яндекс (mobile API + HMAC-подпись), дисковый кэш |
| `src/win.rs` | Окно поверх всех без кнопки на панели задач, регион кликов по форме острова, детектор полноэкранного режима, автозапуск |
| `ui/island.slint` | Весь интерфейс и анимации |

Рендеринг программный (Slint software renderer): для маленького оверлея это намного дешевле, чем держать OpenGL-контекст, и поддерживает прозрачность. Перерисовываются только изменившиеся области.
